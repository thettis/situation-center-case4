# ER-модель — кейс 4 «Ситуационный центр»

## Как заполнять

Дана одна сущность (Site) как образец и связи. Заполни остальные 5 сущностей,
их атрибуты и связи. Для каждой сущности укажи PK/FK, типы и обязательность.

## 1\. Сущности (6+User)

|Сущность|Что хранит|Зачем|
|-|-|-|
|Site|участок: id, имя, зона|привязка датчиков и инцидентов|
|Sensor|датчик: id, участок, показатель, статус|источник показаний, видно какой датчик на каком участке и работает ли он|
|Measurement|показание датчика: время, значение, норма, статус|данные, которые проверяются по порогам|
|Incident|проблема: тип, участок, статус, ответственный, срок|реестр проблем, управление по жизненному циклу|
|Alert|срабатывание правила: уровень (severity), действие|оповестить диспетчера об отклонении|
|AuditEvent|журнал: кто, что и когда сделал|безопасность и разбор спорных ситуаций|
|User|пользователь: id, роль, участок|кто выполняет действия, основа для прав доступа (RBAC)|
**Подсказки:**

* Sensor — датчик, привязан к участку.
* Measurement — показание от датчика (value, time, status).
* Incident — реестр проблем (type, location, status, responsible).
* Alert — результат срабатывания правила (severity, action).
* AuditEvent — журнал для ИБ и разбора споров.

## 3\. Связи (заполни)

|Связь|Тип|Обоснование|
|-|-|-|
|Site → Sensor|1:N|на участке несколько датчиков.|
|Site → Incident|1:N|на участке несколько инцидентов.|
|Sensor → Measurement|1:N|один датчик даёт много показаний.|
|Measurement → Alert|1:N|по одному показанию может быть несколько алертов.|
|Incident → AuditEvent|1:N|каждый переход статуса — событие аудита.|
|Alert → AuditEvent|1:N|каждый алерт — событие аудита.|
|User → Incident|1:N|один пользователь может отвечать за много инцидентов|
|User → AuditEvent|1:N|один пользователь совершает много действий, каждое попадает в аудит|

**Подсказки:**

* 1:N — на участке несколько датчиков / инцидентов.
* 1:N — один датчик даёт много показаний.
* 1:N — по одному показанию может быть несколько алертов.
* 1:N — каждый переход статуса / алерт — событие аудита.
