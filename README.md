# Ситуационный центр — кейс 4

## 1. Описание проекта

Проект представляет собой прототип ситуационного центра для мониторинга показателей объектов, выявления отклонений от нормативных значений и обработки инцидентов.

Система выполняет следующие функции:
- Загрузка данных о показателях и контролируемых объектах из CSV-файлов.
- Проверка полученных показателей на соответствие установленным нормам.
- Определение уровня критичности событий (NORMAL, WARNING, CRITICAL, STALE).
- Формирование оповещений при обнаружении отклонений.
- Автоматическое создание инцидентов при выполнении заданных условий.
- Проверка допустимости переходов между статусами инцидентов.
- Проверка прав пользователей при выполнении операций.
- Запись действий пользователей в журнал аудита.
